# Portafolio Web - Examen Parcial de Diseño Web

**Autor:** Angelo Rojas Velasquez
**Curso:** Diseño Web (ISI-FE2301) - UCH 2026-II

Página de portafolio que hice para el examen parcial. La maquetación es con HTML5 y CSS3, sin librerías ni frameworks.

## Qué usé
- HTML5 semántico: `header`, `nav`, `main`, `section`, `footer`
- Selectores por `id` y por `class`
- Cajas flotantes con `float` y `clear`
- `transition`, `transform` y una animación con `@keyframes`
- `@media` para móvil (menos de 768px) y escritorio (768px o más)
- Audio local con `<audio>` y video de YouTube con `<iframe>`
- SEO básico: `title`, `description`, `keywords`, `viewport` y atributos `alt`
- Publicación en GitHub Pages

## Estructura
```
index.html
css/style.css
img/    (imágenes JPG)
media/  (audio local en mp3)
README.md
```
